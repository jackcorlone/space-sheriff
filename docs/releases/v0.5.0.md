# Space Sheriff v0.5.0

这个版本在 v0.4 可靠性底座之上增加本地可治理能力：版本化策略、清理审计中心和数据库健康维护。

## 主要更新

- 新增稳健、均衡、空间优先三种内置策略
- 支持导入固定 schema、严格校验的本地 JSON 策略
- 策略只能调整年龄和体积阈值，不能关闭系统目录或个人文件保护
- 清理事务记录执行时使用的策略 ID 与版本
- 新增治理中心，展示最近清理事务、计划与实际释放空间以及逐项结果
- 展示 SQLite 完整性、数据库/WAL 大小、索引文件数、扫描会话数和治理事件数
- 支持 WAL checkpoint 与 SQLite optimize，不提供删除审计或任意 SQL 能力

## 数据迁移

- 本地数据库 schema 从 v1 升级为 v2
- v0.5 首次启动会自动迁移 v0.4 数据，并保留文件索引、清理计划和历史事务
- schema 升级是单向的；v0.4 无法重新打开已经升级为 v2 的数据库
- 建议需要降级的用户先备份应用配置目录中的 `index.db`

## 安全与隐私

- 策略导入拒绝未知字段、脚本、表达式、非法 ID 和越界阈值
- 内置策略不可被自定义策略覆盖
- 策略切换只影响后续扫描，不会自动执行清理
- 审计和数据库健康信息仍只通过带随机会话令牌的本机回环接口提供
- 不上传策略、路径、摘要、审计或数据库信息

## 工程改进

- 新增 v1→v2 真实迁移 fixture 测试
- 新增策略差异、保护不降级、版本回退拒绝、审计统计和数据库维护测试
- CI 增加 Go 模块校验，继续执行竞态、覆盖率、前端语法和四平台无 CGO 构建
- 完整设计见 `docs/architecture/v0.5-design.md`

## 尚未包含

系统级后台扫描、签名自动更新、云端策略分发和集中审计需要独立服务与密钥基础设施，不在本版本中。
