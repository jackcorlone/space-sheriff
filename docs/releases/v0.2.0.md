# Space Sheriff v0.2.0

这个版本让“发现大文件”进一步变成可控的空间整理流程。

## 主要更新

- 新增目录空间排行，可从扫描根目录逐层查看体积最大的子目录
- 新增文件名称搜索、风险和类型筛选，以及大小、时间、建议分数排序
- 新增多选和批量移入系统回收站，单次最多处理 500 个文件
- 清理建议增加文件分类、稳定规则编号和更明确的时间依据
- 扫描过程中分批显示大文件结果，长时间扫描更容易掌握进度

## 安全改进

- 本地 API 使用每次启动随机生成的会话令牌
- 删除前重新核对文件类型、大小和修改时间
- 系统与应用目录继续保持禁止清理
- 所有清理仍只移入系统回收站，不做永久删除

## 使用提示

“通常可清理”仍是保守的离线规则判断，不代表绝对安全。请先检查文件用途；
对于个人文件或用途未知的文件，建议先备份。
