# Space Sheriff v0.1.0

首个公开版本提供完全本地运行的磁盘空间分析与安全清理建议。

## 下载选择

- `SpaceSheriff-Windows-x64.exe`：绝大多数 Windows 电脑
- `SpaceSheriff-Windows-ARM64.exe`：Windows ARM 设备
- `SpaceSheriff-macOS-Apple-Silicon-Portable.zip`：Apple Silicon Mac 便携版
- `SpaceSheriff-macOS-Intel-Portable.zip`：Intel Mac 便携版
- `SpaceSheriff-macOS-Apple-Silicon-App.zip`：Apple Silicon Mac 原生窗口版

## 主要功能

- 检测磁盘总容量与可用空间
- 按体积定位大文件
- 显示完整路径、大小和修改时间
- 对缓存、安装包、个人文件和系统文件给出可解释建议
- 清理时只移入系统回收站，并在操作前要求确认
- 所有扫描均在本机完成

## 已知限制

- 删除建议基于保守的离线规则，不代表绝对安全保证
- 二进制暂未使用商业代码签名证书，首次启动可能触发系统提示
- macOS 原生窗口版当前只提供 Apple Silicon 构建
