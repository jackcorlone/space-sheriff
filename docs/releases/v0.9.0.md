# Space Sheriff v0.9.0（原型版）

v0.9 面向第一次使用磁盘分析工具的用户，目标是让扫描报告“能看懂、能判断、能行动”。

## 主要更新

- 新增“新手分析指南”，按位置、大小、时间、原因、重复和下一步动作解释报告；
- JSON 导出增加扫描摘要、错误/排除/预算统计和指南建议；
- CSV 导出增加人类可读大小与下一步动作列；
- 导出区域增加格式说明和本地下载提示；
- 保持本地运行、无云端上传、后台只读和系统路径保护。

## 使用方式

1. 选择用户目录并完成扫描；
2. 先阅读扫描质量和新手分析指南；
3. 在“大文件”区域使用 CSV 做表格筛选，或使用 JSON 查看完整摘要；
4. 只有确认用途、备份和重复组保留关系后，才加入清理计划。

## 已知限制

- 当前导出仍不保存逐条权限错误的原始路径；
- CSV 是文件级明细，扫描级错误/预算摘要在 JSON `summary` 中；
- 导出文件通过浏览器保存到默认下载位置，不自动打开 Excel/Numbers；
- 真实 Windows 任务生命周期、签名 macOS 应用和百万文件实机验收仍不等同于原型完成。

完整设计见 [v0.9 可解释报告与新手引导设计](../architecture/v0.9-design.md)。
