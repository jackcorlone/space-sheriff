# Space Sheriff v0.6.0

这个版本让空间检查可以由操作系统定时触发，同时保持“后台只读、清理由用户确认”的产品边界。

## 主要更新

- 新增每日或每周扫描计划，可配置目录、时间、大文件阈值、重复文件阈值和排除规则
- macOS 便携版使用当前用户 LaunchAgent；Windows 使用当前用户 Task Scheduler
- 同一可执行文件支持 `--scheduled-scan <id> --data-dir <path>` 无界面单次运行
- 新增计划启停、更新、删除和“立即扫描”
- 新增最近计划扫描历史，展示状态、策略、文件数、扫描空间和有限的大文件结果
- 系统任务注册失败会保存错误状态，不会丢失用户的计划配置

## 数据迁移

- 本地数据库 schema 从 v2 升级为 v3
- 增加扫描计划、计划租约、历史结果表，并为扫描会话增加触发来源和策略快照
- v0.6 首次启动会自动迁移 v0.5 数据，保留策略、索引、清理计划和审计记录
- schema 升级是单向的；v0.5 无法重新打开已经升级为 v3 的数据库
- 建议需要降级的用户先备份应用配置目录中的 `index.db`

## 安全与隐私

- 定时扫描只读取文件元数据与内容哈希，只写入 Space Sheriff 本地数据库和任务日志
- 后台入口不调用回收站、永久删除或清理计划接口
- 任务使用当前用户权限，不安装 daemon、Windows Service 或 SYSTEM 任务
- SQLite 租约阻止同一计划同时运行；超过 6 小时的陈旧租约可以安全恢复
- 启动恢复不会改写另一个进程中仍然较新的扫描或清理事务
- 路径、结果、哈希和计划信息不会上传

## 平台说明

- macOS 计划文件位于当前用户的 `~/Library/LaunchAgents`
- Windows 任务名称使用 `SpaceSheriff-<计划 ID>`
- 机器休眠或关机时的补偿触发行为由操作系统决定
- 当前未签名便携版采用原生计划任务接口；未来签名 `.app` 将迁移到 ServiceManagement

## 工程改进

- 新增 schema v3 迁移、计划校验、租约恢复、无界面运行、API 生命周期和平台参数测试
- 保持 65% 覆盖率门槛、竞态检测、Go vet、前端语法检查和四平台无 CGO 构建
- 完整设计见 `docs/architecture/v0.6-design.md`

## 尚未包含

自动清理、系统级服务、签名安装器、签名自动更新、云端策略和集中审计不在本版本范围内。
