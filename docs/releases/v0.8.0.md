# Space Sheriff v0.8.0（开发版）

v0.8 面向百万文件、慢盘和可控运行时间，继续保持本地分析与后台只读。

## 主要更新

- 带 SQLite 索引的扫描按本次会话的文件尺寸逐组查找重复候选，不再在扫描阶段积累全量重复候选数组；
- 同尺寸文件先计算首尾快速指纹，只有快速指纹相同才计算完整 SHA-256；
- 完整哈希以 256 条为一批写入 SQLite，取消时批次回滚；
- 交互式扫描和定时计划可设置逻辑字节预算与最长运行时间；达到预算时状态为 `budget_exceeded`，不会继续重复检测或执行清理；
- SQLite schema 升级到 v4，v3 数据库自动迁移；
- 新增文件量基准测试入口，避免在没有数据的情况下承诺固定性能；
- 界面显示快速指纹、预算状态和计划预算摘要；新增离线 SVG 图标、扫描概览卡片、空间画像和扫描质量面板。
- 扫描质量面板现在分别显示“读取错误”和“规则排除”；资源预算为 0 时明确显示“未设置（不限）”。
- 系统/应用目录在安装包规则前即被标记为受保护，清理入口再次拒绝旧扫描结果中的受保护系统资源。
- 直接打开 `file://` 静态页面时会明确提示必须先启动本地 Go 后端；`run_local.command` 和 `run_local.bat` 提供开发环境启动入口。

## 安全边界

- 预算只限制扫描工作量，不会触发回收站、清理计划或永久删除；
- 定时入口仍不启动浏览器或 HTTP 服务，只保存本地索引和报告；
- SQLite 批次取消会回滚，磁盘写入错误不会被标记为成功完成；
- 快速指纹只是预筛，不替代完整 SHA-256；硬链接仍按物理身份合并。

## 验证

- `GOCACHE=/private/tmp/space-sheriff-gocache go test -race ./...`；
- `go vet ./...`；
- `python3 -m unittest discover -s tests -v`；
- `node --check portable/web/app.js`；
- macOS/Windows 四平台 `CGO_ENABLED=0` 构建和 Windows 测试二进制交叉编译；
- `go test -run '^$' -bench 'Benchmark(ScanManyFiles|IndexedScanManyFiles)' -benchtime=1x` 文件量基准。

基准默认创建 1,000 个文件；可用 `SPACE_SHERIFF_BENCH_FILES=100000` 或 `1000000` 执行目标规模，
并应同时记录耗时、峰值 RSS、数据库大小和取消延迟。

100 万文件、磁盘已满、断电恢复、真实 Windows 任务生命周期和签名 macOS 应用仍需独立机器验收，不能仅凭本地单元测试视为发布完成。

完整设计见 [v0.8 百万文件与慢盘设计](../architecture/v0.8-design.md)。
