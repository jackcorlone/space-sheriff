# Space Sheriff v0.7.0

v0.7 将定时扫描从“保存并触发”提升为可观察、可修复的本地计划功能，继续保持后台只读。

## 主要更新

- 计划卡片显示预计下次运行时间；
- 显示最近一次计划扫描状态和失败原因；
- 识别自上次有效配置或运行以来的错过次数；
- macOS 检查 LaunchAgent 文件与加载状态；
- Windows 检查 Task Scheduler 任务是否存在以及关键参数是否漂移；
- 新增“修复任务”按钮和 `POST /api/schedules/repair` 接口；
- 在本地页面集中显示失败、错过运行、注册错误和任务漂移提醒；
- 清理接口新增 `movedBytes`，明确表示移入回收站的逻辑大小；保留 v0.6 `released` 字段作为兼容别名；
- 不升级 SQLite schema，v0.6 数据库可直接使用。

## 安全边界

- 任务检查是只读的；只有用户明确点击修复时才重新注册系统任务；
- 后台无界面扫描仍不会启动 HTTP 服务、浏览器、回收站或清理计划；
- 不引入系统通知、自动重试、云端服务或自动清理；
- 计划任务继续使用当前用户权限，不安装系统级服务。
