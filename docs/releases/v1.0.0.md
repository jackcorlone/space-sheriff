# Space Sheriff v1.0.0 稳定版候选

日期：2026-08-04
状态：代码与本地验收完成，等待真实双平台签名和系统任务验收后才能发布正式安装包。

## 本版本交付内容

- 冻结 SQLite schema v4、CLI 参数和 `v1` HTTP API 版本契约；
- 新增 `--help`、`--version`，方便脚本和普通用户确认运行版本；
- `/api/version` 返回应用版本、API 版本和数据库 schema 版本；
- 扫描错误增加分类计数和最多 20 条诊断样本，并在 JSON 摘要与扫描质量面板中展示；
- 增加键盘跳转、可见焦点、状态播报和减少动态效果的无障碍基线；
- 保持本地运行、会话令牌、后台只读、系统路径保护和回收站优先策略；
- 保持 CSV 的普通人可读字段与 JSON 的结构化摘要，导出仍由浏览器下载目录接收。

## 升级与回滚

1. 退出正在运行的 Space Sheriff；
2. 备份本地数据目录中的 `index.db`；
3. 使用新版本打开旧数据，v3 数据库会迁移到 v4；
4. 若回滚到不支持 v4 的旧版本，先恢复备份或使用旧版本的独立数据目录；
5. 不要手工修改 SQLite 的 `user_version`。

## 已验证项目

- Go race、vet、build；
- Python 测试、前端语法检查、静态 UI 检查；
- macOS/Windows amd64/arm64 无 CGO 构建；
- 本机本地 HTTP 启动、目录扫描、JSON/CSV 导出和新手引导流程。

## 发布阻断项

以下项目不能在当前开发机上用模拟结果替代，正式发布前必须在独立环境记录证据：

- Windows 11 Task Scheduler 真实注册、启停、睡眠唤醒和卸载；
- Developer ID 签名、公证、SMAppService/LaunchAgent；
- Windows 安装器和代码签名；
- 百万文件、慢盘、磁盘已满、断电/强杀和外置盘拔出恢复；
- 安装升级降级卸载残留矩阵；
- VoiceOver、Narrator、键盘全流程和高对比度回归。

在阻断项关闭前，产物应标记为内部稳定候选，不生成公开 Release 或签名安装器。
