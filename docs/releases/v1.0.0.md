## 本版本亮点

- 冻结 SQLite schema v4、CLI 参数和 `v1` HTTP API 契约
- **清理前时光机**：只读预览预计释放空间、风险与类型构成，可导出模拟报告
- **起飞前检查**：执行前复核文件存在、类型、大小、修改时间与扫描归属
- **空间变化雷达**：对比同一路径两次扫描的新增/变大/变小/离开结果
- 重复文件 SHA-256 识别、清理计划、系统回收站（非永久删除）
- 定时只读扫描（不自动清理）、本地 SQLite、会话令牌、系统路径保护
- 错误分类与有限诊断样本、JSON/CSV 导出、无障碍基线

## 安全承诺

- 扫描不上传文件名或文件内容；数据仅存本机
- 定时任务只读，绝不自动删除
- 清理只移入系统回收站，并在执行前再次核对
- 系统/应用目录受保护；重复组不会一次删光全部副本
- 「通常可清理」是保守离线规则，不是绝对安全保证

## 已知限制

- 无 Apple Developer ID 签名/公证，无 Windows 代码签名
- Windows Task Scheduler / macOS LaunchAgent 真机生命周期未完成外部验收
- 未做百万文件、磁盘写满、断电/强杀、外置盘拔出等压力测试
- 未做完整 VoiceOver/Narrator/高对比度人工验收
