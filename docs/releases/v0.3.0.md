# Space Sheriff v0.3.0

这个版本把重复文件识别和清理前复核加入便携版主流程。

## 主要更新

- 对相同大小的候选文件计算完整 SHA-256，确认内容完全一致后才标记为重复
- 按重复组展示文件、修改时间和最多可释放空间
- 新增清理计划页面，从大文件或重复组加入项目后统一确认
- 新增扫描排除规则，支持目录名、相对路径和绝对路径
- 新增 JSON 与 CSV 结果导出

## 安全设计

- 每个重复组按修改时间建议保留最新副本
- 客户端和本地 API 都阻止一次清理同组的全部文件
- 执行计划时继续复核文件类型、大小和修改时间
- 所有清理仍只移入系统回收站

## 工程改进

- GitHub Actions 升级到 Node.js 24 对应版本
- Go 测试加入竞态检测和最低 65% 覆盖率要求
- 增加重复识别、排除规则、清理计划保护和 HTTP 状态测试
