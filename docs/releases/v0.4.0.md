# Space Sheriff v0.4.0

这个版本不增加新的清理类别，重点提升现有扫描与清理流程的可靠性、恢复能力和可审计性。

## 主要更新

- 新增本地 SQLite 索引，保存扫描会话、文件元数据和内容摘要
- 文件身份、大小和修改时间未变化时复用 SHA-256，降低重复扫描开销
- 使用平台稳定文件身份识别硬链接，避免误报重复副本和虚增可释放空间
- 清理计划持久化，关闭应用后重新打开仍可恢复
- 批量清理增加事务 ID、逐项状态和实际释放空间记录
- 应用异常退出后，未完成扫描和清理事务会被标记为中断并保留记录

## 安全与隐私

- 数据库只存储本机路径、元数据、摘要和操作结果，不存储文件内容，也不上传数据
- 清理前继续校验普通文件类型、大小和修改时间；变化的文件默认跳过
- 所有成功清理仍只进入系统回收站
- 清理日志用于审计与恢复判断，不宣称能够自动回滚已经完成的系统回收站操作

## 工程改进

- 新增 schema 迁移、高版本拒绝、缓存失效、计划恢复和事务中断恢复测试
- 新增硬链接与第二次扫描哈希复用测试
- CI 增加 `darwin/amd64`、`darwin/arm64`、`windows/amd64`、`windows/arm64` 无 CGO 构建验证
- 完整设计与威胁模型见 `docs/architecture/v0.4-design.md`
