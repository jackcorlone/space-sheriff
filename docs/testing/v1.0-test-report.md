## 2. 本地黑盒验收

使用 `run_local.command` 启动本地后端，打开终端输出的带令牌地址：

1. 扫描一个小型本地目录；
2. 等待“扫描完成”，确认扫描质量、空间画像和新手指南更新；
3. 点击 JSON/CSV 导出，确认提示下载文件夹和 JSON `summary`；
4. 对受限目录或不存在路径重试，确认页面显示“扫描失败”或读取错误明细；
5. 确认没有后台清理动作，清理必须由用户显式确认。
