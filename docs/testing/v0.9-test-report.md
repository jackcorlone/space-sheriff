## 原型验收

- 未扫描时显示“从用户目录开始”的四步新手指南；
- 完成扫描后指南切换为“先看建议标签”和“从最大的结果开始”；
- JSON 导出增加 `summary`，包含状态、错误、排除、预算、结果数量和引导建议；
- CSV 增加 `sizeHuman` 与 `nextStep`，原有字段保持；
- 导出前必须完成、停止或达到预算，避免生成空报告；
- 导出仍由浏览器本地生成，不上传文件内容或路径。

## 已知缺口

- 当前没有把逐条权限错误路径写入导出文件；
- 导出目录由浏览器决定，尚未提供“打开下载文件夹”按钮；
- 大型报告尚未分页，百万文件发布验收仍需独立机器和性能证据。
