# Space Sheriff v0.6 黑白盒测试报告

测试日期：2026-07-30  
测试分支：`agent/v0.6`  
测试基线：`8a409f7`

## 1. 范围

本轮针对 v0.6 定时只读扫描进行：

- 白盒：输入边界、SQLite v3、跨进程租约、恢复逻辑、平台任务描述、扫描持久化和安全隔离。
- API 黑盒：令牌、Host、Content-Type、非法 JSON、非法路径、计划读取、立即扫描、状态和历史。
- UI 黑盒：首次加载、计划展开、编辑参数、立即扫描、历史自动刷新、历史详情和控制台错误。
- 构建回归：Go race、覆盖率、vet、前端语法、Python 测试、Windows 测试编译和四平台构建。

测试使用独立的 `/private/tmp` 数据库和文件目录。没有安装真实 LaunchAgent 或 Windows 计划任务；
平台集成通过 macOS `plutil`、确定性参数测试和模拟注册器验证，避免给测试机器留下持久任务。

## 2. 模拟用户流程

1. 无令牌访问 API → `403`
2. 使用伪造 Host 访问 API → `403`
3. 使用 `application/json; charset=utf-8` → 接受
4. 提交未知 JSON 字段或空扫描路径 → `400`
5. 打开已有每周计划 → 正确显示根目录、时间、阈值和排除规则
6. 点击“编辑” → 完整恢复包括非预设阈值在内的参数
7. 点击“立即扫描” → 检查 2 个测试文件并保存 1 条大文件结果
8. 扫描结束 → 状态显示完成，历史从 2 条自动更新为 3 条
9. 点击历史记录 → 展示策略、文件大小、路径、修改时间和判断原因
10. 检查应用页面控制台 → 无错误

## 3. 发现并修复的问题

| 严重度 | 问题 | 影响 | 修复 |
| --- | --- | --- | --- |
| 高 | 计划租约只有固定 6 小时 TTL，没有续期 | 合法长扫描可能被第二个进程并发接管 | 扫描期间每分钟续订；失去租约时取消并报告错误 |
| 高 | JSON 解码忽略未知字段和第二个 JSON 值 | 字段拼错可能退回零值并扩大扫描 | 全部结构化 API 拒绝未知字段和尾随值 |
| 中 | 目录符号链接通过保存校验，但 `WalkDir` 将根视为链接并跳过 | 用户看到“完成”但结果为空 | 保存和前台扫描前解析根目录真实路径 |
| 中 | 自定义计划阈值不在 UI 预设时，编辑后值为空 | 再保存会把阈值悄悄改成 0 | 动态增加“自定义”选项并保留原值 |
| 中 | 立即扫描结束后不刷新计划历史 | 用户误以为报告没有保存 | 完成、取消和失败时自动刷新计划与历史 |
| 中 | 手动计划运行的租约错误可能显示为“已停止” | 并发冲突原因不可见 | 所有运行错误统一进入 error 状态并展示原因 |
| 低 | API 只接受完全等于 `application/json` | 标准 charset 客户端被错误拒绝 | 使用标准媒体类型解析，继续拒绝非 JSON |
| 低 | macOS 卸载把“服务未加载”当作失败，注册失败遗留 plist | 停用失败或下次登录产生幽灵任务 | 区分未找到与权限错误；bootstrap 失败删除 plist |
| 低 | Windows 非英文“任务不存在”错误无法幂等处理 | 中文系统停用不存在任务时可能报错 | 补充英文和中文不存在消息识别 |

## 4. 自动化回归

- JSON：未知字段、尾随值、合法 charset、错误媒体类型。
- 路径：空路径、目录符号链接解析。
- 租约：并发拒绝、过期接管、续期、错误 owner、运行冲突展示。
- 存储：v1→v3 迁移、近期跨进程任务不误恢复、报告持久化、清理计划不受后台扫描影响。
- macOS：plist 参数数组、日历字段、XML 合法性、缺失服务错误分类。
- Windows：带空格路径引用、星期参数、四平台交叉编译。
- UI：自定义阈值保留、立即扫描后历史自动增加、详情可读、无应用侧控制台错误。
