## 文件量基准

基准可用 `SPACE_SHERIFF_BENCH_FILES` 调整文件数量，默认 1,000 个文件。一次性开发参考结果如下，不能视为服务等级承诺：

| 基准 | 文件数 | macOS arm64 |
| --- | ---: | ---: |
| `BenchmarkScanManyFiles` | 1,000 | 3.43 ms/op |
| `BenchmarkIndexedScanManyFiles` | 1,000 | 11.15 ms/op |
| `BenchmarkScanManyFiles` | 100,000 | 316 ms/op |
| `BenchmarkIndexedScanManyFiles` | 100,000 | 1.06 s/op |

基准没有测量峰值 RSS、WAL 增长或取消延迟；发布前应在目标 Windows/macOS 机器上补充这些维度，并执行 1,000,000 文件规模。

## 已知缺口

- 尚未在真实 Windows 11 Task Scheduler、签名 macOS App、睡眠唤醒、断电和磁盘已满环境验收；
- 目录聚合、最终重复组和单个极端尺寸组仍可能占用较多内存；
- 快速指纹不持久化，哈希前后元数据复核和有限错误样本尚未完成；
- 外置盘拔出、网络卷断开和 SQLite 文件系统满时的用户提示仍需要独立实机回归。
