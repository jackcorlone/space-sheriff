Space Sheriff v1.0.0 便携版（内部测试候选）

这是一个完全本地运行的磁盘分析工具。扫描结果、索引和清理计划保存在本机，
不会上传到云端；后台定时任务也不会自动删除文件。

使用方法

macOS：
1. 在终端进入本文件所在目录。
2. 执行 `chmod +x SpaceSheriff`，再执行 `./SpaceSheriff`。
3. 程序会尝试打开浏览器；如果没有打开，请复制终端显示的本地 http://127.0.0.1 地址。

Windows：
1. 双击 `SpaceSheriff.exe`。
2. 如果浏览器没有自动打开，复制程序窗口显示的本地 http://127.0.0.1 地址。

注意事项

- 这是未签名的内部测试包，系统可能显示安全提醒；不要为了运行它而关闭系统安全功能。
- 只使用与你的系统和 CPU 架构匹配的压缩包。
- 不要把浏览器地址中的 `?token=...` 发给别人；它是当前本机进程的会话令牌。
- 不要把本机用户配置目录中的 SpaceSheriff 数据库复制给别人，里面可能包含本机路径和扫描历史。
- 如果你想从源码开发，需要 Go 1.25，并可在仓库根目录运行 `run_local.command` 或 `run_local.bat`。
